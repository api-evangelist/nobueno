# NoBueno (Jungle API)

> NoBueno is a job-and-candidate matching platform (a 500 Global portfolio company). Its "Jungle API" is a Django REST Framework service that powers job postings, candidate profiles, company/employer records, scored job-candidate matching, a skills/roles/disciplines taxonomy, and recruiter-candidate messaging. Authentication is a bearer token obtained via login. This file was generated by the API Evangelist enrichment pipeline from the provider's published OpenAPI and public site.

- [Jungle API (Swagger UI)](https://api.nobueno.com): Interactive documentation for the NoBueno Jungle API (drf-yasg).

## Core operations

- Auth: `login_create` (POST /api/login), `register_create` (POST /api/register), `refresh_create` (POST /api/refresh), `forgot_create` (POST /api/forgot).
- Jobs: `jobs_list`, `jobs_create`, `jobs_read`, `public_jobs_list`.
- Matching: `jobs_matches`, `matches_list`, `users_recommended_jobs`, `users_matches`.
- Profile: `me_list`, `profile_create`, `work-experience_create`.
- Messaging: `messages_list`, `messages_send_message`.
